# AI 草案与 TODO 目录

`docs/spec/` 用于保存 AI 辅助生成的临时方案、TODO 草案、设计备选项和评审记录。
这里的内容不是正式使用文档，也不是长期任务仓库。

## 适用内容

- 新功能实现前的方案草案
- Bug 修复前的原因分析和备选方案
- 重构或迁移前的影响面评估
- AI 生成但尚未人工确认的 TODO
- 需要评审后才能进入 `docs/dev/` 或正式文档的设计记录

## 不适用内容

- 面向使用者的安装、配置、部署说明
- 已经稳定的开发者文档
- 临时日志、完整命令输出、聊天记录
- 真实密钥、token、密码、个人域名、内网 IP
- 已完成且不再需要追踪的历史总结

## 文件命名

使用日期前缀和简短主题：

```text
YYYY-MM-DD-topic.md
```

示例：

```text
2026-04-27-redis-token-cleanup.md
2026-04-27-feishu-user-sync.md
```

## 生命周期

- `draft`：AI 或开发者初稿，尚未评审。
- `reviewing`：正在评审，不能作为最终方案直接实现。
- `accepted`：已接受，可以实施。
- `implemented`：已实现，需要迁移到正式文档或删除。
- `rejected`：已废弃，应保留简短原因后尽快删除。

## 模板

新建草案时复制 [模板](./TEMPLATE.md)，并保留所有元数据字段。
