X OIDC

轻量级 OpenID Connect 身份提供者

🚀 运行中
一个基于 Node.js 和 oidc-provider 构建的现代化 OIDC 身份提供者， 专为 Gitea 等应用提供统一认证服务。支持多种认证方式，包括本地密码和第三方 OAuth。

🚀 可扩展
🔐

OIDC 标准

完全兼容 OpenID Connect 1.0 规范，支持授权码、隐式和混合流程

🔌

插件化架构

支持多种认证提供者，可轻松扩展新的登录方式，如飞书、企业微信、GitHub等

🛡️

企业级安全

使用 bcrypt 密码哈希、JWT 令牌、请求签名验证，确保企业数据安全

⚡

高性能

基于 Fastify 框架，响应速度快，资源占用低，支持高并发访问

📱

现代化 UI

响应式设计，支持移动端，提供优秀的用户体验和统一登录界面

🔄

自动同步

支持 Webhook 事件处理，自动同步用户信息、组织架构和权限变更
